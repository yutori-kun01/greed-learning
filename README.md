# greed-learning — 会員サイト「講座一覧」UI

添付イメージをもとに作成した、会員制ラーニングサイトの講座一覧ページです。
ダークネイビー × ゴールドの配色で、ビルドツール不要の静的フロントエンド（HTML / CSS / Vanilla JS）で構成しています。

## 使い方

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

`index.html` をブラウザで直接開くだけでも動作します。

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | ページ構造（サイドバー / トップバー / 講座グリッド / 右レール） |
| `assets/style.css` | デザイントークン（配色・角丸・影）とレイアウト、レスポンシブ対応 |
| `assets/app.js` | 講座データ、サムネイル SVG の生成、絞り込み・並び替え・検索・ページ送り |

## 実装している機能

- **カテゴリー絞り込み** — すべて / 戦略・思考 / 集客・コンテンツ / 自動化・仕組み化 / 分析・改善 / テンプレート活用
- **並び替え** — 新着順 / 進捗が高い順 / 残りが多い順 / 学習時間が短い順
- **検索** — 講座番号・タイトル・説明文を対象にインクリメンタル検索（`⌘K` / `Ctrl+K` でフォーカス）
- **ページ送り** — 1 ページ 9 講座（全 12 講座）
- **右レール** — 総合進捗のドーナツチャート、学習中の講座、おすすめの次のステップ
- **レスポンシブ** — 1240px 以下で右レールを下段へ、900px 以下でサイドバーを横並びに切り替え

## カスタマイズ

- 講座の追加・変更は `assets/app.js` の `COURSES` 配列を編集します。
  `art` にはサムネイル用モチーフ（`desk` / `chess` / `gears` / `mail` / `chart` / `template` /
  `network` / `rocket` / `workflow` / `scale` / `target` / `brand`）を指定します。
- 右レール「学習中の講座」に出す講座は `LEARNING_NOW` の講座番号で指定します。
- 配色は `assets/style.css` 冒頭の `:root` 変数（`--gold` / `--panel` など）で一括変更できます。
- サムネイルは SVG で描画しているため画像アセット不要です。写真に差し替える場合は
  `.thumb` の中身を `<img>` に置き換えてください。
